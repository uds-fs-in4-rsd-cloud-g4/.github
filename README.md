## 1. Rôle de ce Dépôt Central
Ce dépôt centralise le profil public de l'organisation académique GitHub, ainsi que les modèles universels de contributions (**Pull Request Templates** et **Issue Templates**) applicables à tous les projets du Groupe 4.

## 2. Contenu et Structure
* `profile/README.md` : Landing page officielle de l'organisation de Master 1 RSD.
* `PULL_REQUEST_TEMPLATE.md` : Formulaire obligatoire de validation pour la soumission de PRs.
* `.github/ISSUE_TEMPLATE/` : Modèles de signalement d'incidents et de propositions de RFCs.
* `CHANGELOG.md` : Journal des modifications de l'infrastructure de gouvernance.
